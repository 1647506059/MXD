# 《枫野物语》游戏策划案

版本：0.1.0 ｜ 引擎：Cocos Creator 3.8.8 ｜ 类型：2D 横版动作 RPG ｜ 日期：2026-10-26

## 1. 项目定位

做一段可以从接任务玩到结算的单人横版冒险。面向喜欢轻快跳跃、可爱魔物、打击反馈和角色成长的玩家。参考经典横版冒险 RPG 的类型体验，采用原创名字、角色、美术、地图和剧情。

一句话：来自森林的一封委托，让一名初来乍到的旅人成为古树的守护者。

目标首轮体验约 5–10 分钟，视探索和战斗熟练度而定。设计分辨率 1280 × 720，横屏；优先桌面键盘，同时提供触屏按钮。所有规则与渲染分离，方便增加职业、地图和关卡。

## 2. 体验支柱

| 支柱 | 落地方式 |
| --- | --- |
| 轻快探索 | 横向镜头跟随、单向跳台、二段跳、闪避 |
| 清晰战斗 | 方向近战、范围技能、伤害飘字、受击无敌、首领蓄力提示 |
| 即时成长 | 击败魔物获取经验，升级回满状态并提高攻击与生命 |
| 温暖冒险 | 村庄 NPC、森林委托、任务引导、原创手绘场景与可爱魔物 |

## 3. 核心循环

探索 → 接取任务 → 战斗 → 获取叶片、经验、金币 → 升级和补给 → 领取任务奖励 → 首领挑战 → 传送门结算。

普通魔物会重生，保证资源可持续获得。若玩家在接取任务前已击败魔物，依然可以等待重生继续任务。角色倒下返回村庄，保留任务与等级，扣除 10% 金币。莉娅提供免费状态恢复及最低药水补给，避免失败后无法继续。

## 4. 角色控制

| 项目 | 当前参数 |
| --- | --- |
| 横移速度 | 285 像素/秒 |
| 重力 | 1800 像素/秒² |
| 首跳初速度 | 660 像素/秒 |
| 二段跳初速度 | 590 像素/秒 |
| 闪避速度 / 持续 | 900 像素/秒 / 0.17 秒 |
| 闪避冷却 / 无敌 | 1.1 秒 / 0.27 秒 |

平台仅在下降且跨过平台顶面时承接角色；上升可穿过。离开平台后需要跳跃或回落，全部关卡下方铺设地面，首章无需坠落死亡惩罚。角色与攻击均限制在地图边界内。

## 5. 战斗与成长

| 参数 | 数值 |
| --- | --- |
| 初始等级 / 生命 / 魔力 | 1 / 120 / 70 |
| 普攻伤害 | 23 +（等级 − 1）× 7 |
| 普攻冷却 / 前向范围 | 0.32 秒 / 145 像素 |
| 枫叶旋风 | 2 倍普攻伤害，角色周围 270 像素 |
| 技能消耗 / 冷却 | 18 魔力 / 1.7 秒 |
| 魔力恢复 | 每秒 5 点 |
| 升级所需经验 | 当前等级 × 70，升级扣除本级所需经验 |
| 每次升级 | 最大生命 +24，最大魔力 +8，状态回满 |
| 初始恢复药水 | 5 瓶，每瓶恢复 65 生命 |

命中判定结合水平距离、面朝方向和高度差。普攻只伤害前方；旋风可命中左右多个目标。每次攻击只结算一次，按住 J 按冷却重复挥斩。技能与药水均检查资源，禁止负魔力或负库存。

## 6. 魔物设计

### 叶灵

绿色果冻状森林精灵，头上两片嫩叶。10 只分布在林地地面与高台。生命 48，接触伤害 12；以每秒 42 像素在出生点左右约 74 像素巡逻。击败提供 30 经验、12 金币；接受任务后额外获得一片任务叶片。金币靠近自动吸附，或 6 秒后自动收取。普通魔物 23 秒后在远离玩家时重生，守卫净化后停止重生。

### 古树守卫

树枝与苔石组成的原始守护者。生命 520，位于圣域。任务奖励领取前受祝福屏障保护，玩家也无法进入圣域。

状态机：休眠 → 巡逻 → 蓄力 → 震击与地面能量 → 恢复 → 巡逻。

- 玩家靠近且取得祝福后启动战斗。
- 巡逻速度 35 像素/秒，接触伤害 18。
- 蓄力 0.95 秒，锁定蓄力开始时的玩家位置，用宽 250 像素的橙色区域预警。
- 震击伤害 30。离开预警区域或跳到地面以上 100 像素即可避免震击。
- 震击同时向左右释放速度 265 像素/秒的地面能量球，伤害 22，可跳跃或闪避穿过。
- 震击后恢复 1.35 秒；生命低于一半时缩短下一次巡逻等待，增加节奏压力。
- 击败后提供 180 经验、120 金币，清除场上能量球，开启星光之门。

## 7. 第一章关卡

地图宽 5200 像素，设计视口 1280 × 720；地面高度 144。镜头在角色前方保留探索视野，以插值跟随并限制边界。背景以 0.13 倍镜头速度移动形成视差。

| 区域 | 横坐标范围 | 内容与目的 |
| --- | --- | --- |
| 风铃村 | 0–649 | 初始出生、莉娅、委托、补给、圣域路碑 |
| 翡翠林地 | 650–3799 | 10 只叶灵、8 座跳台、回村路碑，熟悉战斗和跳跃 |
| 古树圣域 | 3800–5199 | 任务屏障、古树守卫、星光之门 |

跳台高度为 266、380、272、392、280、386、268、350，依次分布；相邻高差允许首跳或二段跳到达。既可走地面完成任务，也可探索平台。村口路碑 x=570 在领取奖励后开放，直达圣域入口；林中 x=2110 的路碑可返回村庄。

## 8. 任务与剧情状态

| 状态 | 触发 | 反馈 / 下一步 |
| --- | --- | --- |
| 0 待接取 | 莉娅身边按 E，接受委托 | 进入收集阶段 |
| 1 收集叶片 | 击败 5 只叶灵 | 更新屏幕任务计数 |
| 2 待领奖 | 叶片达到 5；回村与莉娅交谈 | 奖励仅可领取一次 |
| 3 守卫挑战 | 获得 80 金币、80 经验、3 瓶药水及古树祝福 | 开放路碑和圣域 |
| 4 传送门开放 | 守卫生命归零 | 引导前往右侧星光之门 |
| 5 第一章完成 | 星光之门附近按 E | 展示结算，保存通关状态 |

任务信息始终显示在 HUD，Q 可查看完整步骤；交互提示只在附近出现。对话框支持按钮、E 或 Enter 确认。Esc 关闭当前弹窗，未确认的任务奖励不会提前发放。

## 9. 界面和反馈

奶油白、深青绿与暖金构成界面配色。顶部为项目名、任务、背包、暂停、音效。左上生命魔力与等级，左侧任务卡；右上小地图显示玩家位置及三区关系。底部经验、金币、药水、键盘提示；右下技能按钮显示冷却。

命中飘字、金币数字、升级光环、技能弧光、受击闪烁、角色呼吸与行走缩放、环境萤火共同提供反馈。七种原创合成音效覆盖攻击、技能、跳跃、拾取、受伤、升级与胜利。切出窗口自动暂停，避免离开时持续受伤。

## 10. 存档与实现

使用 Cocos `sys.localStorage`，键名 `maplewild-cocos-388-v1`。保存角色属性、位置、任务、击杀、魔物、掉落及首领状态；重要事件立即保存，游玩中每 5 秒保存。读档校验版本和关键字段。读档时角色回到当前位置地面，清除空中速度，避免半空载入异常。

`GameModel.ts` 负责模拟和事件；`AdventureGame.ts` 负责 Cocos 场景和交互。碰撞为自定义单向平台规则，无需物理引擎；首章主要对象使用原生 Sprite / Graphics / Label。UI 与世界层分离，扩展地图与怪物时可保持界面独立。

## 11. 已实现与后续范围

本次完成上述单人第一章、全部核心战斗和任务闭环，以及原画资源、音效、工程入口和验证脚本。挥剑采用四帧角色动画，移动和待机使用原画配合程序动画；平台及界面为 Cocos Graphics。底栏显示命中或未命中状态，J 和攻击按钮均支持按住连续挥斩。

后续可制作逐帧跑跳受击动画、独立地块贴图、更多地图、装备词条与多职业。在联网、多人交易、付费和账号系统之前，需要另做服务端和经济设计；这些不属于本次单人原型。
