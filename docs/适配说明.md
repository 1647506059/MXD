# 窗口与屏幕适配

游戏设计尺寸为 1280 × 720。所有平台保持 16:9 等比缩放，游戏区域居中；更宽的窗口留左右边，更窄的窗口留上下边。完整保留任务、状态、触屏按钮和弹窗，画面不会横向拉伸。竖屏也能操作，横屏下文字和按钮更大。

## 本次修复

1. 编辑器预览只缩放了设计界面，却继续绘制超出边界的地图。现在在 `GameScreen` 使用原生 Cocos 矩形 Mask，将背景、地图、HUD、特效及弹窗裁剪到同一个区域；留边不再出现魔物、路碑或地面。
2. 预览中的暂停遮罩现在覆盖完整游戏区域，弹窗保持居中。
3. CSS 改变了容器尺寸后，Creator 3.8 可能保留旧渲染分辨率。现在通过 ResizeObserver 和窗口尺寸事件同步 Cocos `screen.windowSize`，并保留宿主的响应式样式，避免按钮点击坐标漂移。
4. Web 构建模板支持动态视口高度 `dvh` 和 `safe-area-inset-*`，避免移动浏览器工具栏或安全区域遮挡内容。
5. 监听随场景销毁清理，尺寸更新按帧合并，尺寸相同时不重复更新渲染分辨率。

## 验证

执行 `npm run test:viewport` 验证本地 Cocos 3.8.8 构建，需先运行 `npm run preview`。默认共 16 组检查：网页模板五种窗口、模拟编辑器全画布五种窗口、DPR 2 的全画布五种窗口，以及安全区域模拟。

| 窗口 | 用途 |
| --- | --- |
| 1466 × 642 | 用户截图对应的宽屏嵌入区域 |
| 1280 × 720 | 标准 16:9 |
| 1024 × 768 | 4:3 |
| 844 × 390 | 手机横屏 |
| 390 × 844 | 竖屏 |
| 960 × 540，四边安全留距 | 移动设备安全区域模拟 |

检查包括：留边像素为纯背景色，没有越界地图；游戏比例和完整范围正确；运行中反复调整窗口后，暂停按钮与攻击按钮可以准确点击；暂停遮罩覆盖游戏左右上角。机器可读结果见 `适配验证结果.json`。

另对截图所用的 `localhost:9527` 嵌入预览进行了相同的五种尺寸检查，结果见 `适配预览验证结果.json`。该宿主的运行内核报告为 4.0.0；项目发布构建及工程目标仍为 Cocos Creator 3.8.8，两者均已验证。

嵌入预览宿主缺少 `favicon.ico`，其 404 单独记录为 `hostWarnings`，不计作游戏脚本错误；游戏资源和输入验证未因此跳过。

本次验证使用 Chrome 自动化及模拟屏幕，不代表已完成实体 Android/iOS 设备验证。
